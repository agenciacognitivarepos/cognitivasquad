# Visual Review

## Process
1. Analisar as imagens PNG geradas pelo Tico Técnico na pasta `output/images/`.
2. Verificar se o design segue o padrão de cores (#0B1B32) e tipografia da marca.
3. Avaliar a legibilidade dos textos em cada slide.
4. Garantir que os assets 3D estão com aparência profissional e não distorcidos.
5. Emitir o veredito final (Aprovado ou Reprovado com correções).

## Output Format
Markdown report with image analysis and final score.
