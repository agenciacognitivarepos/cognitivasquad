# Anti-Patterns: O que NÃO fazer no Instagram B2B

## Never Do
1. **Falar apenas de "Features"**: Executivos não se importam se o modelo é GPT-4 ou Llama-3. Eles se importam com o impacto no P&L.
2. **Usar Emojis em Excesso**: Diminui a percepção de autoridade senior.
3. **Posts de "Sextou" ou "Bom dia"**: Irrelevantes para o posicionamento premium da consultoria.
4. **Design Poluído**: Muitos elementos visuais tiram o foco da mensagem estratégica.

## Always Do
1. **Trazer Dados Reais**: "X milhões de eventos processados" é melhor que "muitos eventos".
2. **Citar o Método C.O.R.E**: Reforça a metodologia proprietária.
3. **Contraste de Consultoria**: Sempre mostrar a diferença entre "vender projeto" e "construir produto".
